Applied UI kits

Three build variants of the same applied, invented "browse properties / mensajes" product concept — same tokens, same copy, same product surfaces, each rebuilt in a different stack. None of these are extracted product fact; see each kit's README and DESIGN.md §9 for that caveat.

React

app-react/

CDN React + ReactDOM + Babel standalone, no build step — opens directly in a browser. The fastest way to preview the applied concept.

 Astro + Tailwind

app-astro/

Real .astro components matching the archived source's actual stack. Requires a Node/Astro build step (npm run dev).

 Svelte + Tailwind

app-svelte/

Real .svelte components with idiomatic Svelte reactivity. Requires a Node/Vite build step (npm run dev).

This page is a hub, not a fourth kit — it has no components of its own. Pick a card above based on your target stack; each kit's README documents its structure, usage, and design notes.
