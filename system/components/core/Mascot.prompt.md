All 31 renders ship in `assets/mascot/`. Pick by pose/category via `assets/mascot/manifest.json`
(label/category/confidence per render, same schema as the iconset's `labels.json`). Pair Capi
side-by-side with text, never behind it.

every other render wears the documented navy-vest/white-shirt/maroon-tie look — an unreconciled
inconsistency (see `assets/mascot/manifest.json` and `DESIGN.md`), don't treat either as more
canonical.
