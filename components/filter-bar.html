Filter bar component

A search/filter panel: three underline fields (comuna, price range) plus a property-type toggle group rendered as pill buttons — the active type uses .btn-primary, the rest .btn-outline (DESIGN.md §6 Buttons). Copied from ui_kits/app-react/components/FilterBar.jsx, which reuses ContactForm.astro's underline-input pattern: no boxed/bordered text fields anywhere in this system. Depends on colors_and_type.css's .card, .input-underline, and .btn classes plus the rules below.

On toggle, swap the clicked button to .btn .btn-primary and every sibling back to .btn .btn-outline — never leave more than one type visually active at once. aria-pressed (added above; not present in the source JSX) keeps the toggle state exposed to assistive tech, matching this system's own focus/disabled interaction-states requirement in DESIGN.md §6.1.
