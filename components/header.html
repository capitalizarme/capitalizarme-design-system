Header component

Sticky, translucent top nav — wordmark + 2 nav links + a pill CTA button ("Agenda tu reunión"), the system's persistent single call-to-action (DESIGN.md §8 Voice & Brand). Copied from ui_kits/app-react/components/Header.jsx, itself applied from Header.astro (see source-evidence/capitalizarme-boilerplate-html/components/Header.astro, which used a plain text link — the CTA is promoted to a real button here to match how the CTA is treated everywhere else in the system). Copy the markup below as-is; it only depends on colors_and_type.css tokens (including .btn/.btn-primary) and the classes defined in the <style> block above.
