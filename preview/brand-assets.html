Horizontal logo — assets/logo/horizontal/ (7 color variants)

The current flat-color lockup batch (dated "070726"), including Verde and Azul Oscuro (dark navy). Filenames use the current "sin com" naming — Capitalizarme's active wordmark drops the ".com" suffix used throughout the archived 2020/2021 BrandBook. Blanco (white) is shown on a navy tile for legibility — always place it on a dark or brand-blue surface, never on white. Note: embedded ink colors here are close to but not identical to the §2.1 official tokens — treat as decorative logo colors, not a UI token source.
