Official iconset — assets/icons/iconset/

This 124-glyph set is Capitalizarme's official iconset for product UI — the default icon source for any new design work, ahead of ad-hoc or AI-generated icons. Auto-extracted from a Figma frame exported in 6 color layers: the original grayscale/ink export (4123×1773, 311 raw paths) plus 5 flat-color re-exports of the identical frame — Verdes, Azules, Rojos, Amarillo, Celestes (each also 311 raw paths). Every color layer was clustered and bounding-box matched back to the grayscale reference, so icon-NNN is the same shape/position in every color — only the fill changes.

Every glyph now carries a semantic label — each was visually reviewed and named by content (e.g. icon-116 "Property / apartment", icon-079 "Cart / purchase"), grouped into 8 categories below, and recorded in assets/icons/iconset/labels.json. Labels marked with a gold ? are a best visual guess on an abstract glyph — confirm the read before adopting one of those for a specific recurring use. Pick a glyph by label or category filter, not by memorizing grid position; when a glyph is adopted for a specific recurring use, promote it into a named file mirroring assets/icons/step-*.svg. Use the color switcher to preview any icon in any of the 6 available colors — see manifest.json (grayscale) and manifest-colors.json (5 color families) for path-count and fill metadata.
